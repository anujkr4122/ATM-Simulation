# 🏧 ATM Simulation System (C++)

A simple **ATM Simulation System** built using **C++**. This project demonstrates the fundamentals of C++ programming including functions, file handling, loops, conditional statements, and menu-driven programming.

## 🚀 Features

- 🔐 PIN Authentication
- 💰 Balance Enquiry
- 💵 Deposit Money
- 💸 Withdraw Money
- 🔄 Change PIN
- 💾 File Handling (Data Persistence)
- 📋 Menu Driven Interface

## 🛠️ Technologies Used

- C++
- File Handling
- Functions
- Loops
- Conditional Statements

## 📂 Project Structure

```
ATM-Simulation/
│
├── ATM.cpp
├── atm.txt
└── README.md
```

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/ATM-Simulation.git
```

2. Compile

```bash
g++ ATM.cpp -o atm
```

3. Run

```bash
./atm
```
